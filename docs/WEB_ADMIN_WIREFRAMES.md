## Catatan RBAC pada Wireframe

Visibilitas menu sidebar & tombol aksi (Create/Edit/Delete/Generate) dikontrol oleh `RoleGate` mengikuti matrix 4-role (`SUPERADMIN`, `ADMIN`, `ADMIN_RTUPP`, `USER`). Wireframe menampilkan superset; tiap role hanya melihat item yang diizinkan (lihat `docs/DESIGN_SYSTEM.md` & `TDD_FRONTEND.md §5`). RBAC backend tidak diubah.
